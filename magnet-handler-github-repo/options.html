Magnet Handler for qBittorrent

Right-click any magnet or .torrent link and choose Send to qBittorrent.

First time setup

In qBittorrent open Tools → Options → Web UI (on Mac: qBittorrent → Settings → Web UI):
  1. Tick Web User Interface (Remote control).
  2. Note the Port (default 8080) and set a username and password.
  3. Click Apply / OK, then fill in the same details below.

Connection

Same computer: http://localhost:8080. Another machine on your network: http://192.168.1.50:8080.
